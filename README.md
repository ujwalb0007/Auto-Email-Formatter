# 📨 Auto Email Formatter (Python CLI Project)

A professional **command-line email generator** built in Python using the **Jinja2 templating engine**.  
It transforms your rough notes or bullet points into a **clean, formal email** instantly — perfect for quick professional communication.

---

## 🚀 Features

- 🧠 **Smart Formatting:** Converts rough input into a structured email  
- 🧾 **Dynamic Template:** Uses Jinja2 to fill in placeholders automatically  
- 💾 **Auto Save:** Option to save your formatted email as a `.txt` file  
- 📅 **Auto Date Insertion:** Adds current date automatically  
- 🔤 **Clean Output:** Removes extra spaces, ensures proper capitalization  

---

## 🧠 Tech Stack

- **Language:** Python 3  
- **Libraries:**  
  - `Jinja2` — for templating  
  - `re` — for text cleaning and normalization  
  - `datetime` — for timestamps
